# 背景图资产目录

## 说明

此目录用于存放 YouTube 封面的背景模板图。

**重要**：这些背景图是"只读品牌资产"，Skill 不会修改或生成背景图。

## 需要的文件

请将以下 4 张背景图放置在此目录：

- `background_green.png` - 绿色背景（看涨）
- `background_red.png` - 红色背景（看跌）
- `background_blue.png` - 蓝色背景（中性）
- `background_yellow.png` - 黄色背景（警示）

## 建议规格

- 尺寸：1280 × 720（标准 YouTube 16:9）
- 格式：PNG
- 设计建议：留出中部偏左区域用于叠加标题文字
