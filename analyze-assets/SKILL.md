# analyze-assets: 币圈视频资产时间轴分析

## 目标

基于字幕文件（SRT）自动分析视频中提到的所有币种和股票，并输出它们的时间范围（开始时间、结束时间、时长）。

**输入**：
- 字幕文件（`3daily/简体MMDD.srt`）
- 该字幕文件是根据 `draft.txt`（用户审核修改后）生成的

**输出**：资产时间轴表格（markdown格式）+ JSON 文件（包含完整时间范围）

---

## 重要说明：字幕与文稿的关系

**字幕文件（SRT）是根据 draft.txt 生成的**，不是直接从 ASR 生成：

1. 音频 → 火山引擎 ASR → 生成原始识别结果
2. 原始识别结果 → 应用币圈字幕规则 → 生成 `draft.txt`（供审核）
3. **用户审核修改 `draft.txt`**（如修正"一探访"→"以太坊"）
4. **根据修改后的 `draft.txt` 生成最终字幕文件（SRT）**

因此，字幕内容应该与 `draft.txt` 保持一致。如果发现字幕内容与 `draft.txt` 不一致，需要：
1. 修正字幕文件（`sed` 替换）
2. 或重新生成字幕（基于 `draft.txt`）

## 处理流程

### 步骤 1：读取字幕文件

解析 SRT 字幕文件，提取每条字幕的时间戳和内容。

### 步骤 2：读取文稿文件（可选）

读取 `draft.txt`，补充字幕中可能省略的币种名称（如XLM）。

### 步骤 3：识别资产关键词

搜索以下关键词模式：

**过渡短语**：
- "我们来看一下"
- "我们看一下"
- "再看一下"
- "看一下其它的"
- "我们再来看"

**币种/股票名称**：
- 比特币、BTC、大饼
- 以太坊、ETH、以太
- 黄金
- XLM、Stellar
- 英特尔
- 美光
- 其他币种名称

### 步骤 4：计算时间范围

对于每个识别到的资产：
1. 找到包含该资产名称的第一条字幕，记录**开始时间**
2. **初步结束时间**计算逻辑：
   - 当前资产的结束时间 = 下一个资产的开始时间
   - 最后一个资产的结束时间 = 视频总时长（从字幕获取）
3. **优化结束时间**（排除连接话）：
   - 从初步结束时间向前扫描最多8条字幕
   - 识别明确的连接话/过渡语（如"OK好"、"那另外一个是"、"所以美股"等）
   - 将结束时间调整到连接话之前
   - 确保不包含跨币种的过渡内容
4. 格式化为 `HH:MM:SS,mmm`

### 步骤 5：生成时间轴表格

输出 markdown 格式的表格，包含：
- 序号
- 资产名称
- 开始时间
- 结束时间
- 时长（秒或分钟）
- 简要说明

## 注意事项

1. **字幕来源**：字幕文件是根据 `draft.txt`（用户审核修改后）生成的，内容应与 `draft.txt` 保持一致
2. **币种识别**：基于字幕中的关键词匹配资产名称（比特币、以太坊、黄金等）
3. **时间轴计算**：

4. **修正机制**：如果字幕内容错误（如 ASR 识别错误"一探访"），应修正 `draft.txt` 后重新生成字幕

## 技术细节

### 时间戳解析

SRT 时间戳格式：`HH:MM:SS,mmm`

转换逻辑：
```python
def parse_srt_time(time_str):
    """解析 SRT 时间戳为毫秒"""
    h, m, s_ms = time_str.split(':')
    s, ms = s_ms.split(',')
    return int(h) * 3600000 + int(m) * 60000 + int(s) * 1000 + int(ms)
```
