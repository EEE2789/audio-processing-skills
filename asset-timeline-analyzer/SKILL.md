# 资产时间轴分析器

## 目标

基于视频字幕文稿（final.txt），自动分析视频中提到的所有资产（比特币、以太坊、山寨币、美股等）的时间轴，包括历史操作、当前状态、未来目标和操作建议。

**输入**：final.txt（视频字幕文稿）
**输出**：资产时间轴分析报告（Markdown 格式）

## 使用方法

### 基本用法（自动读取最新文稿）

```bash
python3 /Users/ai/.claude/skills/asset-timeline-analyzer/scripts/analyze_timeline.py
```

自动读取 `/Users/ai/Documents/video_pipeline/3daily/final.txt`

### 指定文稿路径

```bash
python3 /Users/ai/.claude/skills/asset-timeline-analyzer/scripts/analyze_timeline.py /path/to/final.txt
```

## 处理流程

### 步骤 1：读取文稿

自动从 `/Users/ai/Documents/video_pipeline/3daily/final.txt` 读取最新视频字幕文稿。

### 步骤 2：调用 DeepSeek 分析资产

使用 DeepSeek API 分析文稿，提取以下信息：

**每个资产包含**：
1. **资产名称**：比特币、以太坊、XMR、英特尔、美光、特斯拉等
2. **当前价格/状态**：最新价格或当前状态描述
3. **历史操作**：过去提到的操作（做多、做空、止盈、推荐等）
4. **浪形分析**：技术分析中的浪形结构描述
5. **风险提示**：提到的重要风险或警告
6. **未来目标**：目标价格或预期走势
7. **操作建议**：当前应该采取的操作（观望、等待、开仓等）

### 步骤 3：生成时间轴分析报告

将 DeepSeek 返回的分析结果整理成 Markdown 格式的报告，包括：

- **资产概览表**：所有资产的简要状态对比
- **详细时间轴**：每个资产的详细分析
- **关键时间节点**：需要重点关注的时机
- **整体结论**：市场整体情况和策略建议

### 步骤 4：输出报告

在终端显示分析报告，并保存到文件。

## 输出格式

### 资产概览表

```markdown
| 资产 | 过去操作 | 当前状态 | 未来目标 | 操作建议 |
|------|----------|----------|----------|----------|
| BTC | 做空止盈→做多 | 观望 | - | 等方向明确 |
| ETH | - | 观望 | - | 等方向明确 |
```

### 详细时间轴

```markdown
### **1. 比特币（BTC）**
- **当前价格**：64,500左右
- **当前状态**：观望（行情清淡，方向不明）
- **历史操作**：
  - 前期：一线位上涨 → 做空单止盈
  - 中期：做多单
  - 当前：回到中间位置，上下皆可能
- **浪形分析**：
  - 情况1：a浪上涨 → b浪回调 → c浪上涨
  - 情况2：b浪走复杂ABC结构
- **操作策略**：上来做空 OR 下来做多，中间不操作
```

### 关键时间节点

```markdown
## 🎯 关键时间节点

1. **XMR**：密切关注330支撑位是否跌破
2. **特斯拉**：等待Y浪结构明确（WXY下跌 OR 三角形）
3. **美光**：确认第3浪是否完成
```

## 环境变量

在 `.env` 文件中设置 DeepSeek API Key：

```
DEEPSEEK_API_KEY=your_api_key_here
```

## 边界说明

**本 Skill 做**：
- 读取 final.txt 文稿
- 调用 DeepSeek 分析资产时间轴
- 生成结构化的 Markdown 报告
- 在终端显示并保存报告

**不做**：
- 视频处理
- 价格获取
- 交易建议执行
- 历史数据记录

## 与 Video4 的关系

本 skill 基于最终字幕文稿（final.txt）进行分析，该文稿是由 Video4 处理流程生成的：

1. **Video4 生成**：从原始视频生成带字幕的 Video4
2. **字幕提取**：从 Video4 提取字幕文件
3. **文稿生成**：生成 final.txt 文稿
4. **时间轴分析**：本 skill 分析文稿中的资产时间轴

因此，本 skill 是视频处理流程的下游分析工具，用于帮助用户快速理解视频中提到的所有资产情况和操作建议。
