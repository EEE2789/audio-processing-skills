# coin-metadata: 币种视频元数据生成

## 目标

为剪辑好的币种视频（除比特币外）生成完整的元数据：
1. **5字封面标题**（显示在控制台，用于后续制作封面）
2. **80字视频标题**（包含前后缀，参照 Video3 格式）
3. **重命名视频文件**

**输入**：
- 资产时间轴（`3daily/assets_timeline.json`）
- 文稿文件（`3daily/final.txt`，可选）
- 币种视频（`2output/MMDD{币种名称}.mp4`）

**输出**：
- 重命名的视频文件（`2output/MM.DD{币种}价格今日行情：{标题}（{币种}合约交易）军长.mp4`）
- 封面标题（5字，显示在控制台）

## 处理流程

### 步骤 1：读取资产时间轴

从 `assets_timeline.json` 读取币种列表。

### 步骤 2：跳过比特币

比特币是主视频内容，跳过不处理。

### 步骤 3：生成标题（调用 DeepSeek）

**封面标题（5字）**：
- 偏交易、行情、走势判断
- 不使用营销、夸张词汇
- 参考风格：短期见底没、反弹后再跌、关注82阻力

**视频标题内容（80-100字）**：
- 几句话总结行情分析
- 包含主要分析要点
- 保留所有标点符号

### 步骤 4：生成完整视频标题

参照 Video3 格式：
```
MM.DD{币种}价格今日行情：{内容}（{币种}合约交易）军长
```

**格式规则**：
- 内容末尾自动去除句号
- 后缀前不加任何标点符号

示例：
```
06.13以太坊价格今日行情：当前价格处于关键支撑位，MACD底背驰信号明显，短期有望反弹（以太坊合约交易）军长
```

### 步骤 5：重命名视频文件

从 `MMDD{币种名称}.mp4` 重命名为 `MM.DD{币种}价格今日行情：{标题}（{币种}合约交易）军长.mp4`

## 文件组织规则

**重要**：只有正式发布版视频才能放在 `2output/` 文件夹，中间剪辑文件必须放在 `3daily/` 文件夹。

### 文件夹用途

| 文件夹 | 用途 | 内容 |
|------|------|------|
| `2output/` | 正式发布版 | 最终发布给用户的视频（Video1/2/3/4、币种视频） |
| `3daily/` | 中间文件 | 剪辑过程中的片段文件、临时文件 |

### 文件分类

**正式发布版**（放在 `2output/`）：
- Video1 油管繁体：`1繁体MMDD...mp4`
- Video2 简体版：`2简体MMDD...mp4`
- Video3 字幕版：`3字幕MMDD...mp4`
- Video4 剪辑源：`4字幕MMDD.mp4`
- 币种视频：`MM.DD{币种}价格今日行情...mp4`

**中间文件**（放在 `3daily/`）：
- 剪辑片段：`eth_intro_MMDD.mp4`、`eth_content_MMDD.mp4`
- 字幕备份：`简体MMDD.srt.bak.*`
- 音频文件：`MMDD_YYYYMMDD.wav`

### 错误示例

❌ **错误**：将剪辑片段放到 `2output/`
```
2output/eth_intro_0721.mp4     # 错误！这是中间文件
2output/eth_content_0721.mp4   # 错误！这是中间文件
```

✅ **正确**：将剪辑片段放到 `3daily/`
```
3daily/eth_intro_0721.mp4      # 正确！中间文件
3daily/eth_content_0721.mp4    # 正确！中间文件
```

## 注意事项

1. **必须先生成币种视频**：运行 clip-coins skill 生成币种视频
2. **必须先生成资产时间轴**：运行 analyze-assets skill 生成 assets_timeline.json
3. **比特币被跳过**：比特币是主视频内容，不单独处理
4. **文件名长度限制**：macOS 文件名长度限制约为 255 字节，中文占用更多字节，超长会自动截断
5. **封面标题字数验证**：会验证封面标题是否为 5 个字，不是则警告但继续执行
6. **封面标题只显示**：封面标题只在控制台显示，不生成封面图片

---

## 错误处理

| 错误 | 处理 |
|------|------|
| assets_timeline.json 不存在 | 提示错误，建议先运行 analyze-assets |
| 未找到币种视频文件 | 跳过该币种，继续处理下一个 |
| DeepSeek API 调用失败 | 提示错误，跳过该币种 |
| 封面标题不是 5 个字 | 警告但继续执行 |
| 重命名目标文件已存在 | 覆盖原文件 |

为每个币种视频生成 5 字封面标题（显示）、80 字视频标题（含前后缀），并重命名视频文件为标准格式。
