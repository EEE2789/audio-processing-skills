# asset-videos: 资产视频自动生成

## 目标

基于资产时间轴分析结果，为每个币种生成独立视频。

**输入**：assets_timeline.json（资产时间轴）
**输出**：每个资产生成独立视频（包含开头介绍）

## 使用方法

### 基本用法（自动生成所有资产视频）

```bash
python3 /Users/ai/.claude/skills/asset-videos/scripts/generate_asset_videos.py
```

## 处理流程

### 步骤 1：读取资产时间轴

从 `3daily/assets_timeline.json` 读取所有资产的时间范围。

### 步骤 2：获取 Video4

使用 Video4 作为视频源（已包含字幕和1.1倍速）。

### 步骤 3：提取开头介绍

提取"我是军长"结束前的片段（所有视频共用）。

### 步骤 4：为每个资产生成视频

对每个资产：
1. 提取资产内容片段
2. 拼接开头介绍 + 资产内容
3. 生成独立视频文件

## 输出文件

### 文件位置

`/Users/ai/Documents/video_pipeline/2output/`

### 文件命名

格式：`MM.DD{币种}价格今日行情：{内容}（{币种}合约交易）军长.mp4`

**示例**：
- `06.29以太坊价格今日行情：结构跟比特币一样，b浪宽幅震荡，小级别双锯齿反弹接近阻力位，1760附近压力明显，随时可能破位下行，今天需警惕（以太坊合约交易）军长.mp4`
- `06.29NEAR价格今日行情：大周期上升五浪后的ABC调整，C浪五浪尾声，若触及目标区间正式观察（NEAR合约交易）军长.mp4`
- `06.29XLM价格今日行情：猛烈反弹后ABC下跌，C浪第5浪尾声，当前位置结束可能性大，正式列入观察（XLM合约交易）军长.mp4`

## 依赖

- Python 3
- FFmpeg（`/opt/homebrew/bin/ffmpeg`）
- Video4（`4字幕MMDD.mp4`）
- 资产时间轴（`assets_timeline.json`）

## 注意事项

- 所有视频都包含开头介绍（"我是军长"部分）
- 标题目前为简化版本，后续可集成 DeepSeek 生成
- 视频使用标准编码参数（CRF 15, veryfast）
- 时间轴完全基于资产时间轴分析结果

## 边界说明

**本 Skill 做**：
- 读取资产时间轴
- 提取开头介绍片段
- 为每个资产生成独立视频
- 拼接开头介绍 + 资产内容

**不做**：
- 重新生成 Video4
- 修改字幕
- 分析资产时间轴（由 analyze-assets 完成）
- 生成标题（当前为简化版本）
