### 自我介绍特殊处理

**规则**: 在字幕开头（前10秒/约前30条），所有"我是XX"格式统一替换为"我是军长"

**示例**:
- `我是村长` → `我是军长`
- `我是军长` → `我是军长`（保持不变）
- `我是某某` → `我是军长`

**实现方式**: 使用正则表达式 `^我是(.+)$` 进行替换，匹配"我是"后面的任意内容并替换为"军长"

### 实现要点
- 使用全局正则替换
- 不区分大小写（对于英文币种符号）
- 在所有其他处理前执行

## 2. 数字口语化规则

### 触发条件
仅处理 ≥ 10000 的连续整数。

### 转换规则

| 原数字 | 转换结果 | 说明 |
|--------|----------|------|
| 10000 | 1万 | 整万转换 |
| 93000 | 9万3 | 简化表示 |
| 103000 | 10万3 | 大额简化 |
| 93542 | 93542 | 保留精确（避免误伤价格） |

### 实现要点
- 匹配 `\b(\d{5,})\b` 模式
- 仅当 remainder < 1000 时简化
- 精确价格（如 93542）保持不变

---

## 3. 断句与行宽控制

### 目标行宽
- 单行: 12-18 汉字
- 允许自然换行，避免过碎

### 禁止情况
- 2-3 字单独成行
- 完整句子被切得过碎
- 标点符号单独占一行

### 示例

❌ 错误：
```
现在
行情
非常关键
```

✅ 正确：
```
现在行情非常关键
```

## 4. 语气词清理

### 基础语气词（可删除）
```
嗯、啊、呃、欸、哎、噢、哦、唔、嗯哼
```

### 句首语气词（可删除）
```
这个、那个、就是、然后、其实、可能、我觉得、你看、对吧、好吗
```

### 句尾语气词（可删除）
```
呢、嘛、吧、呀、啊、啦、喽
```

### 保护机制
包含专业术语时，仅删除明确的语气词，保留句法结构。

---

## 5. 行尾标点规则

### 规则
- 单行字幕结尾不保留标点
- 行内可保留自然停顿标点

### 示例

| 原文 | 处理后 |
|------|--------|
| 现在行情非常关键， | 现在行情非常关键 |
| 先点这里，再点那里 | 先点这里，再点那里 |
