# jz字幕

## ⚠️ 核心原则（必须遵守）

**字幕必须基于用户审核后的 draft.txt 生成，这是整个流程的关键环节。**

**火山引擎 ASR 识别有很多错误**（如"一探访"→"以太坊"），所以必须：
1. 先生成 draft.txt 供用户审核
2. 用户人工修改 draft.txt 中的错误
3. **根据审核后的 draft.txt 生成最终字幕**
4. 后续所有视频都使用这个审核后的字幕

**如果跳过审核，字幕会包含大量错误，视频烧录的就是错误的字幕！**

---

## 目标

将音频文件转换为币圈行情分析视频专用的简体/繁体中文字幕。

**输入**：音频文件（wav/mp3/m4a）
**输出**：`简体MMDD.srt`（简体）+ `繁体MMDD.srt`（繁体）+ `final.txt`（简体文稿）
- 例如：2026年02月04日生成 `简体0204.srt` 和 `繁体0204.srt`

## 处理流程

```
1. 调用火山引擎语音识别（带字级时间戳）
   ↓
2. 生成 raw SRT
   ↓
3. 应用币圈字幕规则
   ↓
4. 输出字幕稿（draft.txt）供用户审核
   ↓
【用户审核修改】（⚠️ 强制步骤，不可跳过）
   ↓
5. 根据用户修改生成最终文件
   ↓
6. 输出 简体MMDD.srt（简体）+ 繁体MMDD.srt（繁体）+ final.txt（简体文稿）
```

### 脏字完全删除（2026-05-02 新增）

以下脏字直接删除（不影响正常词汇）：
- **妈的、他妈的、他妈** - 完全删除
- **屄、肏、操、草** - 仅删除独立出现的脏字，不影响"操作"、"草稿"等正常词汇

### 脏字兜底替换（2026-05-02 新增）

⚠️ **强制规则**：字幕中不允许出现"阴"、"逼"等脏字。

如果所有替换完成后，字幕中仍然出现这些字：
- **自动替换为 `*`**（如：阴影 → *影）
- **保护专业术语**：阴线、逼仓、逼迫等不受影响

### 2. 数字口语化

≥10000 的数字转为币圈读法：

- `93000` → `9万3`
- `100000` → `10万`
- `93542` → `93542`（精确价格保留）

### 3. 断句控制

- 单行 12-18 汉字
- 最少 4 个字，少于 4 字的不单独成行
- 避免标点单独占一行

### 4. 语气词清理

删除无意义的口语赘词：嗯、啊、呃、哈、呢、这个、那个、然后、就是...

**保护机制**：包含专业术语时仅删除明确语气词。

### 5. 行尾标点

- 单行结尾不保留标点
- 行内保留自然停顿标点

## 字幕审核（强制）⚠️

**字幕必须经过人工审核才能生成最终文件**，这是强制要求：

### 审核流程

1. 火山引擎转录完成后，生成 `draft.txt` 审核稿
2. **强制暂停**，等待用户审核修改
3. 用户审核通过后，明确告知"审核通过"或"可以生成"
4. **只有收到用户明确确认后**，才能生成最终字幕

### 重要说明

- ❌ **没有跳过审核的选项**
- ❌ **不允许使用快速模式（不带参数直接生成）**
- ✅ **每次生成字幕都必须经过人工审核**
- ✅ 必须使用 `--draft` 参数先生成审核稿
- ✅ 等待用户确认后，才能使用 `--final` 生成最终文件

### 正确的命令序列

```bash
# 步骤1：生成审核稿（必须）
node scripts/process_subtitles.js volcengine_result.json output_dir/ --draft

# 步骤2：等待用户审核修改 draft.txt

# 步骤3：用户确认"审核通过"后，生成最终字幕
node scripts/process_subtitles.js volcengine_result.json output_dir/ --final
```

### 错误示例（禁止）

```bash
# ❌ 禁止：直接生成最终字幕，跳过审核
node scripts/process_subtitles.js volcengine_result.json output_dir/
```

## 使用方法

### 完整流程（含火山引擎转录 + 用户审核）

```bash
# 1. 设置 API Key（首次使用，已配置）
# .env 文件中已设置 VOLCENGINE_API_KEY

# 2. 从音频文件生成火山引擎转录结果

## 方式一：使用 shell 脚本（推荐）
./scripts/volcengine_api.sh audio.wav

## 方式二：手动调用（当 uguu.se 不可用时）

# 步骤1：上传音频到临时文件服务
curl -s -F "files[]=@audio.wav" https://uguu.se/upload > upload_response.json

# 步骤2：提取音频 URL
AUDIO_URL=$(cat upload_response.json | python3 -c "import sys, json; data=json.load(sys.stdin); print(data['files'][0]['url'])")

# 步骤3：提交转录任务
API_KEY="your_api_key"
SUBMIT_RESPONSE=$(curl -s -L -X POST "https://openspeech.bytedance.com/api/v1/vc/submit?language=zh-CN&use_itn=True&use_capitalize=True&max_lines=1&words_per_line=15" \
  -H "Accept: */*" \
  -H "x-api-key: $API_KEY" \
  -H "Connection: keep-alive" \
  -H "content-type: application/json" \
  -d "{\"url\": \"$AUDIO_URL\"}")

# 步骤4：提取任务 ID
TASK_ID=$(echo "$SUBMIT_RESPONSE" | python3 -c "import sys, json; data=json.load(sys.stdin); print(data.get('id', ''))")

# 步骤5：轮询等待结果（最多 10 分钟）
for i in {1..120}; do
  sleep 5
  QUERY_RESPONSE=$(curl -s -L -X GET "https://openspeech.bytedance.com/api/v1/vc/query?id=$TASK_ID" \
    -H "Accept: */*" \
    -H "x-api-key: $API_KEY" \
    -H "Connection: keep-alive")

  STATUS=$(echo "$QUERY_RESPONSE" | python3 -c "import sys, json; data=json.load(sys.stdin); print(data.get('code', ''))")

  if [ "$STATUS" = "0" ]; then
    echo "$QUERY_RESPONSE" > volcengine_result.json
    echo "✅ 转录完成"
    break
  elif [ "$STATUS" = "1000" ]; then
    echo -n "."
  else
    echo "❌ 转录失败: $QUERY_RESPONSE"
    break
  fi
done

# 输出: volcengine_result.json（带字级时间戳）
# 说明: 上传音频到 uguu.se，调用火山引擎 API，轮询获取结果

# 3. 生成字幕稿（供审核）
node scripts/process_subtitles.js volcengine_result.json output_dir/ --draft

# 输出: draft.txt（纯文本，不含时间戳）
# 审核稿会自动在默认编辑器中打开

# 4. 用户审核修改 draft.txt

# 5. 根据修改后的稿子生成最终字幕
node scripts/process_subtitles.js volcengine_result.json output_dir/ --final

# 输出: 简体MMDD.srt（简体）+ 繁体MMDD.srt（繁体）+ final.txt（简体文稿）
# 例如: 简体0204.srt + 繁体0204.srt + final.txt
```

### 火山引擎 API 说明

**API 端点**：
- 提交任务：`https://openspeech.bytedance.com/api/v1/vc/submit`
- 查询结果：`https://openspeech.bytedance.com/api/v1/vc/query`

**请求参数**：
- `language=zh-CN`：中文识别
- `use_itn=True`：逆文本标准化（数字转文字）
- `use_capitalize=True`：首字母大写
- `max_lines=1`：每段一行
- `words_per_line=15`：每行最多 15 个词

**返回格式**：
```json
{
  "id": "任务ID",
  "code": 0,
  "message": "Success",
  "utterances": [
    {
      "text": "字幕文本",
      "start_time": 0,
      "end_time": 5000,
      "words": [...]
    }
  ]
}
```

**状态码**：
- `0`：成功完成
- `1000`：处理中
- 其他：失败

## 时间戳完整性 ⚠️

**字幕时间戳必须与火山引擎转录完全一致**，这是强制要求：

### 完整性保证

1. **保留所有语段的时间戳**，包括：
   - 少于 4 个字的短字幕（如"破了"、"OK"）
   - 处理后可能变空的语段（使用原文）

2. **自动补充缺失语段**：
   - 如果 `draft.txt` 的行数少于火山引擎语段数
   - 自动使用原始处理后的文本补充缺失的语段
   - 确保最终字幕的时间戳完整

3. **时长校验**：
   - 生成最终字幕时自动校验音频时长
   - 字幕最后结束时间必须与火山引擎转录结束时间一致
   - 允许差异：0 秒（完全一致）

| 字幕最后结束时间 | 202.06 秒 (00:03:22,060) |
| **差异** | **0.00 秒** ✅ |

- 常用字：买→買、卖→賣、图→圖、线→線、号→號、价→價、万→萬、亿→億

## 故障排除

### 字幕时间不匹配

**症状**：字幕时间与音频不同步，结束时间差异超过2秒

**检查步骤**：
1. 查看生成日志中的时长校验信息
2. 确认 "火山引擎转录结束" 和 "音频时长" 差异是否小于2秒
3. 如果差异很大，检查：
   - 火山引擎是否完整转录了音频
   - 字幕时间戳单位是否正确（毫秒）
   - `allUttsLastEnd` 是否正确计算

**已知的修复**（2026-03-16）：
- 修复了结束时间计算bug
- 优化了时间戳匹配逻辑
- 添加了调试信息

如果遇到时间不匹配问题，查看 `/Users/ai/.claude/memory/subtitle_timestamp_fix.md`

### 字幕数量异常

**症状**：生成的字幕数量与预期不符

**可能原因**：
1. `draft.txt` 行数与火山引擎语段数不匹配
2. 过多语段被 `text.length >= 4` 过滤器排除

**解决方案**：
- 查看日志中的 "匹配字幕" 信息
- 确认 `draftLines`、`validUtts` 和匹配数量
- 如果差异过大，检查 draft.txt 是否有过多短行
